# Matriz 0.1.0-rc.1

Proposed release candidate for the engineering laboratory. It includes the project and task workspace, account sessions, project membership, comments, multiple assignees, search, filtering, and progress.

Use the [README](README.md) to configure PostgreSQL and start the development stack. Run [verification](docs/verification.md) before treating the candidate as ready for delivery. This version serves development over local HTTP with demonstration accounts enabled only when configured for that environment. A published release and any GitHub workflow evidence depend on a subsequent approved Git operation.
